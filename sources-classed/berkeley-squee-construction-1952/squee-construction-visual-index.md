# Squee Construction Visual Index

This file is an image-first guide to Edmund C. Berkeley's `Squee` construction
plans. It is intentionally not a full transcription. The source is diagram
heavy, caption heavy, and scan noisy, so the most reliable way to use it is to
navigate by extracted page images and only then consult OCR when needed.

Related files:

- [OCR draft](squee-construction-1952-ocr.txt)
- [Page images directory](/home/cartheur/ame/aiventure/aiventure-github/monographs/symbolic-logic/figures/berkeley-squee-construction-pages)

## Highest-Value Pages

- `page-03`: readable general description of `Squee` as a behaving robot
- `page-09`: steering column and eye/tube arrangement
- `page-10`: mechanical parts list
- `page-11`: electrical parts list
- `page-13` to `page-18`: circuit sheets
- `page-19`: operating instructions

## Recommended Use

- Use the page images as the primary source.
- Use the OCR draft only to search for candidate words or labels.
- Use `The Construction of Living Robots` for cleaner Berkeley prose about what
  `Squee` is and why it matters.
