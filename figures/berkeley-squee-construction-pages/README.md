# Berkeley Squee Construction Pages

This directory contains page-image extracts from:

- `sources/Berkeley--Squee construction.pdf`

The source PDF is effectively an image-per-page scan, so the most faithful
"figure extraction" is page extraction. These JPEGs are therefore intended as
the primary visual reference for the `Squee` construction plans.

## Files

- `page-01.jpg`: cover/title page
- `page-02.jpg`: contents
- `page-03.jpg` to `page-09.jpg`: general description and construction views
- `page-10.jpg` to `page-12.jpg`: mechanical/electrical/main circuit parts lists
- `page-13.jpg` to `page-18.jpg`: circuit sheets
- `page-19.jpg`: operating instructions
- `page-20.jpg`: final page / tail matter

## Notes

- These are extracted directly from the embedded page images rather than
  reconstructed from OCR.
- For readable prose about what `Squee` does, prefer
  `sources-classed/berkeley-the-construction-of-living-robots-1952/`.
- For a page-by-page navigation aid, see
  `sources-classed/berkeley-squee-construction-1952/squee-construction-visual-index.md`.
